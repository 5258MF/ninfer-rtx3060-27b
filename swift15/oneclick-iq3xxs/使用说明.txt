Swift 1.5 IQ3XXS MTP-Q4 便携启动包 0.1.4

解压到空目录，双击“启动.bat”。不要覆盖旧包或源码目录。
首次使用会下载约 10.33 GiB 的 IQ3XXS 原始模型，并用包内补丁转换 MTP-Q4。
转换前需要约 21 GiB 空闲磁盘；下载支持断点续传，全文件 SHA256 验证后才转换。
已有 swift15_iq3xxs_mtpq4.ninfer 可放进 model 目录，或设置 NINFER_IQ3_MODEL 指向它。
模型文件没有包含在 ZIP 内。启动器不需要 Python 或独立 CUDA Toolkit。

默认 RK4V4、关闭 CUDA Graph、CPU 视觉、自动 CPU 线程、128K 总上下文。
显存驻留容量按启动时真实空闲显存估算；可选推荐值、自动上限或手动容量。
系统/工具前缀、检索和输出由引擎按请求分配，没有固定 SYS/检索/输出分区。
CUDA Graph、容量和余量估算不保证所有硬件组合的极限容量。

启动.bat dryrun：只预览参数，不下载、不加载模型。
预览参数.bat：预览当前配置。
测试.bat：引擎启动后检查接口并发起短请求。
verify-kit-manifest.ps1：校验分发文件。
默认接口 http://127.0.0.1:8084/v1 ，模型 ID qwen3.8-27b。
CPU 视觉仍需语言模型、特征交接及 KV 使用 GPU。
